# docs/

外部引用资料、身份材料与需要长期保存的原文。**不是**员工的工作笔记。

## 放什么

- 老板提供的身份、背景、术语材料。
- 外部文章、规范、数据集的原文或摘录。
- 需要跨任务复用的参考资料。

不放：任务草稿、日志、报告、临时脚本、生成缓存。

## 规则

- 保留原文，不随意改写；需要批注时另建 `*.notes.md`，不覆盖原文。
- 文件名用“主题”而不是“日期”，除非同一主题有多个版本。
- 每份外部资料尽量在文件头注明：来源 URL、获取日期、作者/机构、许可（如已知）。
- 不确定授权的内容只放链接与短摘录，不整篇搬运。
- 不放密钥、token、个人隐私、未公开的内部数据。
- 本目录的 README 负责索引；新增资料时同步登记。

## 命名建议

```
<主题>.txt / <主题>.md / <主题>.pdf
<主题>.notes.md      # 批注
<主题>.<版本>.md     # 同主题多版本
```
