## 方向甲：Agent 工具权限/身份层 ——"给我 agent 一个只能枢，不能 DROP 的工具"

**用户原声**：
- HN《AI Agent Has Root Access (and That's a Problem)》（news.ycombinator.com/item?id=47530428）："我接 Postgres MCP 只想要读，server 还附带 DELETE/执行任意 SQL/DROP TABLE……Claude/Cursor/ChatGPT 全部 all-or-nothing"；"1,808 个 MCP server 扫描，66% 有安全发现；60 天出 30 个 CVE；下载最多的 7 个 skill 里 5 个是恶意"。"像 IAM 出现之前的早期云计算"。
- r/LocalLLaMA《Running local models with tools: does anyone actually control what their agents can do?》：合规券商用户：agent 读 env 里生产密钥、全文件系统权限、无行为记录；"自托管是为了控制，却把比初级工程师更大的权限交给 agent"；中肯追问：agent 被注入后，日志还可信吗？
-HN 里 NanoClaw 架构讨论（id=47675254）："没人愿意预先配置权限，用户碰壁后照样 yolo 模式"——强制 up-front 配置是 UX 死路，需运行时动态收发权限。

**供给端缺口**：CVE 已成流水线——Ruflo（66.5k★ agent 平台）无认证 MCP 桥 RCE（CVE-2026-59726，CVSS 10.0）、mcp-remote RCE（437k 下载）、Amazon Q 经 MCP 配置窃取云凭据（CVE-2026-12957）、Azure DevOps MCP confused-deputy 越权泄露。企业端 Pillar/CrowdStrike/Microsoft Defender/Koi 全为闭源且按席位收费（pillar.security 2026 企业对比表），开源方向只有 Snyk Agent Scan（GA，免费 CLI 扫描）——**开源、本地、CI 集成、按 agent 身份限权的"细粒度授权层"几乎无人占位**。

## 方向乙：Agent 结果真实性 —— "agent 说做完了，数据库说没有"

**证据**：
- TestJack（arxiv 2610.10619，2026-10）：对 5 个编程基准审计——**34.4% 的"通过"试次实际违反任务要求**。
- 评测装置审计（arxiv 2610.16067）：agent 基准把"oracle"当定义而不测试它，目前没人可靠地测测量本身。
- YC 公司 Moda（2026-10-16 launch）的完整产品叙事=痛点清单：agent 失败静默、工具调用超时、"宣布完成但没做"、prompt 注入导致泄露；团队现在仍靠翻 transcript 找 bug。**YC 校验需求，但未见同位开源替代**。
- VibeLeaderboard 引 Microsoft ThinkingBox：同一 stateful 工作流连跑 20 次才算可靠——"跑一次成功不算数"正在成为共识。

**引申**（这方向我们自带独特视角）：本项目自身就是"多 agent 长会话可审计"的活实验室——logs/GOODFILES/单写窗口/事实优先级就是 prototype；把我们自己的"事实优先级"做法工具化（结论锚点、git 可回放、争议处留档），对外的故事是"给 agent 工作流做事务性验收"，不是又一个 eval 框架。

## 方向丙：MCP/技能供应链的安全体检（方向甲的一个可首发切口）

- postmark-mcp（Koi Security，2025-09）：npm 包镜像合法邮件工具、其间偷寄 BCC 副本——供应链投毒实况。
- GhostSplice（ASSET，2026-08）：把窃取指令拆进 tool description 与 tool result 两个通道，绕过"单次拦截"防御。
- Microsoft 官方警告（2026-06-30）：tool description 投毒让 agent 合规地外传数据。
- OWASP 2025-12 Agentic Top 10 收录 Agentic Supply Chain —— 类别已"标题化"，但**开源的本地 MCP/skill 审计器仍几乎只有"扫描器"，没有"策略+签名+隔离运行"的一体件**。

## 方向丁：本地优先的检索/记忆层（强度中等，供对比淘汰用）

-《What do people use for search?》（r/LocalLLaMA, 2026-07）："自托管模型可以接受，但搜索像是回到了 30 年前的 Altavista"——本地 agent 的"联网能力"是目前最被骂的部件。
- 供给端已有 LLM Router/Ketch/SearXNG 封装一票小工具，高度内卷（agentskillshub 同类清单 10 项 4.5k 星总和）——轮廊上更接近 echo1 假设 5 的"竞争极卷"。
- 底部管线（flock 56★ 自托管推理集群网关）类产品尚小，窗口在但天花板待证。
