**我最初的几个方向假设（只作为靶子，不是结论）**：

1. **Agent 工具/权限的“安全与审计层”**：MCP 生态爆发，但谁能看清 agent 到底调用了什么、改了什么、泄露了什么？可做本地审计/策略网关。
2. **AI 代码的 provenance / slop 检测**：代码库越来越多人机混合，review 时无法判断“这段是谁写的、可不可信”。可做 git-native 的 provenance 工具。
3. **可复现的 agent 实验台**：不是又一个 eval 框架，而是“给 agent 工作流做单元测试 + 回放 + 成本账单”。
4. **视频/多模态研究的基础设施**：老板的集群与视频模型背景是优势；但受众可能窄，需要包装成“任何多模态实验都能用”。
5. **本地优先的个人知识/记忆层**：需求大，但竞争极卷，除非有强差异（可验证、可删除、跨应用）。
